These are the pre-respondami-specific versions of the `refine`,
`code-health-check`, and `arch-review` skills, archived before the PreCompact
hook work (see `docs/plans/2026-10-24-other-skill-hooks-design.md`). The

copies here are the harness-agnostic versions, kept for use in other harnesses.

so it is not treated as a skill by the loader.
